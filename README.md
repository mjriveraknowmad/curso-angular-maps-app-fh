# MapsApp

Este proyecto es de carácter educativo, del curso de angular de Fernando Herrera: https://www.udemy.com/course/angular-fernando-herrera, en este caso centrado en el uso de mapas en angular, de la mano de mapbox.

## Levantar proyecto en Dev

1. Instalar dependencias
2. Generar el `.env` basado en el `.env.template`
3. Ejecutar el comando `npm run set-envs` . Esto generará los archivos de environments.ts y environment.development.ts (archivos que están añadidos en el gitignore para no subirlos por accidente)
